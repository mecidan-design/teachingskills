# Programa de seguimiento de notas (Inglés Primaria)

Este programa en Python te permite registrar alumnos, cargar evaluaciones y revisar reportes por alumno o por curso.

## Skills evaluadas

El sistema incluye 5 skills:

1. Listening
2. Speaking
3. Reading
4. Writing
5. Use of English

> Si quieres cambiar los nombres, edita la lista `SKILLS` dentro de `seguimiento_notas.py`.

## Requisitos

- Python 3.10+

## Uso

```bash
python3 seguimiento_notas.py
```

Se guardará un archivo `datos_alumnos.json` automáticamente en la misma carpeta.

## Flujo recomendado

1. Registra todos tus alumnos por curso.
2. Registra evaluaciones periódicas por skill (nota de 0 a 10 y observación opcional).
3. Consulta reportes individuales para tutorías/familias.
4. Consulta reportes de curso para ver panorama general.
